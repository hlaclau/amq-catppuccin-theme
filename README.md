## Usage

1. Install [Stylus](https://add0n.com/stylus.html) for your browser.
2. [Install the userstyle](https://github.com/hlaclau/animemusicquiz-catppuccin-theme/raw/master/catppuccin.user.less).
3. Open the Stylus popup on [AnimeMusicQuiz](https://animemusicquiz.com/) and pick your flavor and accent color.

> [!NOTE]
> Latte is intentionally not supported, as it doesn't work well with this website. Frappé, Macchiato and Mocha are available, with all accent colors.

## 🙋 FAQ

- Q: **_"How do I set a custom wallpaper?"_**\
  A: Paste an image URL into the **Wallpaper URL** field in the Stylus options for this style. Leave it empty for the default flat background. Browsers can't load local `file://` paths, so host the image online or use a `data:image/...;base64,...` URL.

- Q: **_"How do I change the flavor or accent color?"_**\
  A: Click the Stylus icon in your browser toolbar, then adjust the options under this style.

- Q: **_"Why is there no Latte?"_**\
  A: The website's design doesn't hold up with a light palette, so it was removed.
